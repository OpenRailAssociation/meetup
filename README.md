# OpenRail Community Meetup

This repo is the home of the regular OpenRail Community Meetup.

We are meeting online every second Thursday in a month at 14:00 CEST.

The meetup is a public event open to everyone interested in OpenRail and discussing open source in the context of railways.

If you have any questions or are interested in presenting a topic please reach out to meetup@openrailassociation.org.
